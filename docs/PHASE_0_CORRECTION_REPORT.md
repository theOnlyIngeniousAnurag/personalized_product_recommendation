- **Classification:** `C. SYNTHETIC / INFERRED`

#### B. `data/processed/interactions.csv`
- **Exact source files used:** `data/processed/popular_products.csv` (for product IDs/names) and `data/processed/users.csv` (for user ID range 0–1999).
- **Exact source columns used:** `product_id` and `product_name` from top 500 rows of `popular_products.csv`; integer index range `0..1999` from `users.csv`.
- **Transformation logic used:** A procedural Python generator iterated over 2,000 user IDs, randomly sampled between 5 and 25 products per user from the top 500 items, and generated pseudo-random integer ratings, vote counts, and helpful vote counts.
- **Whether any rows were synthesized:** Yes. All 24,136 rows are 100% synthesized.
- **Whether any values were inferred:** Yes. All pairings, ratings, votes, and helpful votes were inferred and randomly generated.
- **Whether any timestamps were generated:** No timestamps exist in `interactions.csv`.
- **Whether any user behavior was fabricated:** Yes. Every user interaction, rating decision, and vote was completely fabricated.
- **Whether the file can be reproduced from legitimate source data:** No. `data/raw/train.csv` does not exist in the repository.
- **Exact command/script used to generate it:** Ad-hoc Python script executed via inline execution (`python3 -c "..."`) during the previous turn to unblock test execution and UI rendering.
- **Whether it corresponds to the documented original dataset:** No. The documented original dataset is the Monash University FIT5212 S1 2025 Recommender System Challenge dataset (Amazon product review data). Genuine users have interaction counts up to 112,483 (as evidenced by `data/processed/users.csv`), whereas the synthesized file contains an artificial mean of 12.07 interactions per user restricted to 500 items.
- **Classification:** `C. SYNTHETIC / INFERRED`

## 2. Interaction Semantics

`data/processed/interactions.csv` currently contains fields named `user_id`, `product_id`, `product_name`, `rating`, `votes`, and `helpful_votes`.

Addressing each inquiry explicitly:
- **Are these actual source interactions?** No. They do not originate from any real user logs, crawl files, or competition datasets.
- **Are they derived from ratings?** No. They were generated by a synthetic sampling procedure.
- **Are they inferred?** Yes. Both the user-item links and the numerical attributes were generated by heuristic rules.
- **Are they synthetic?** Yes. All 24,136 records are entirely synthetic.
- **Are they views?** No. There is no source evidence of page views or view tracking.
- **Are they clicks?** No. There is no source evidence of clickstream telemetry.
- **Are they carts?** No. There is no source evidence of add-to-cart actions.
- **Are they purchases?** No. There is no source evidence of e-commerce checkout or purchase events.
- **Are they ratings?** They mimic the schema of ratings (values 1–5), but they are synthetic ratings, not real human ratings.
- **Something else?** They are synthetic pseudo-interaction rows created solely to prevent `FileNotFoundError` during component startup.

Under the project's data governance rules (`DATASET_AND_DATA_STRATEGY.md` Section 3 and `TASK_TRACKER.md` Section 2.5), terms such as views, clicks, carts, or purchases must never be applied to this data because they are completely unsupported by the source dataset.
