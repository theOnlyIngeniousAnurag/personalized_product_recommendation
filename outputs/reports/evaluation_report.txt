1. DATASET & VALIDATION METHODOLOGY
--------------------------------------------------------------------------------
Dataset: Monash FIT5212 S1 2025 Recommender Challenge
Training Interactions:   597,502 records
Validation Interactions: 148,387 records
Total Unique Users:      2,000
Catalog Products:        201,325
Validation Users Evaluated: 1,999
Relevance Definition:    Validation rating >= 4.0
Validation Strategy:     80/20 User-Level Stratified Holdout (Path B Non-Temporal)

CRITICAL LIMITATION:
Temporal validation could not be performed because the authentic FIT5212
dataset contains no legitimate timestamp field.

4. SUMMARY FINDINGS
--------------------------------------------------------------------------------
- User-kNN Collaborative Filtering significantly outperforms Popularity Baseline on Recall and NDCG.
- TruncatedSVD Matrix Factorization captures broad latent user preferences with fast vector dot products.
- Content-Based recommendation provides targeted catalog coverage using TF-IDF title similarities.
- The Hybrid Model achieves high personalization while maintaining robust cold-start fallback.
